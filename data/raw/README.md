# Raw documents

Download the four specs below as PDFs and save them here with the file names shown.
The PDF versions are published for free by ETSI (3GPP's European partner), so the
spec numbers are written as "TS 1xx xxx" on the ETSI site. Use Release 17 or 18.

| Save as        | 3GPP spec | ETSI spec      | Topic        |
|----------------|-----------|----------------|--------------|
| `ts_38300.pdf` | TS 38.300 | ETSI TS 138 300 | radio_access |
| `ts_23501.pdf` | TS 23.501 | ETSI TS 123 501 | architecture |
| `ts_23502.pdf` | TS 23.502 | ETSI TS 123 502 | procedures   |
| `ts_33501.pdf` | TS 33.501 | ETSI TS 133 501 | security     |

How to find them: search for the ETSI spec number (for example "ETSI TS 138 300"),
open the etsi.org "deliver" page, pick the latest version and download the PDF.
